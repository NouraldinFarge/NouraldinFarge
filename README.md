## Engineering approach

- Keep user data local, portable, and recoverable.
- Make trust boundaries explicit at the desktop/filesystem edge.
- Validate imported data with schemas, provenance, and deterministic rules.
- Treat tests, release assets, checksums, SBOMs, and attestations as product evidence.
- State methodology and product limits directly—especially in analytics and financial education.
