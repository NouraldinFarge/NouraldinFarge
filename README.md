# Hi, I'm Nouraldin Farge

I build local-first Windows desktop software where reliability, privacy, and honest product boundaries matter as much as the interface.

My current work combines React and TypeScript frontends with Rust/Tauri or Electron desktop authorities, SQLite persistence, defensive import pipelines, versioned contracts, and portable release automation.

## Active projects — 2026

### [DrawScope](https://github.com/NouraldinFarge/drawscope)

A local-first lottery research workbench with reproducible data lineage, cross-language contracts, and leakage-resistant walk-forward evaluation. React · Rust · Tauri · Python · SQLite.

### [GameVault](https://github.com/NouraldinFarge/gamevault)

A portable game library and launcher with a review-gated ZIP intake pipeline, defensive archive handling, and optional allowlisted store metadata. React · Rust · Tauri · SQLite.

### [Day-Trading Teacher](https://github.com/NouraldinFarge/day-trading-teacher)

An educational trading environment for curriculum-guided planning, historical chart replay, deterministic risk practice, journaling, and post-trade review—without live signals or order execution. React · Rust · Tauri · SQLite.

### [Research Studio — Case Study](https://github.com/NouraldinFarge/research-studio-case-study)

A source-free case study of a guarded AI-assisted catalog-enrichment workflow built around read-only SQLite access, working copies, schema validation, human approval, and recoverable exports. Electron · React · TypeScript · SQLite · Playwright.
